# Project Watt Cubed Licensing Audit

Audit date: 2026-07-24

## Scope and status

This is a technical provenance audit of the `project_watt_cubed` Git
repository. It does not cover the separate `voxel-engine` repository,
constitute legal advice, or replace a dependency-licence and asset-provenance
scan.

The ownership-identification phase is resolved:

- all human commit identities have been classified;
- the maintainer confirmed that they supplied the previously questioned
  patches, including commit `3b2b11212c6e322d45237dab82b8106380c7ee84`;
- no unattributed current asset pack or vendored source tree was found; and
- the named nontrivial contributors have been identified for direct
  relicensing confirmation.

The licensing-transition commit must not be pushed or published until direct
written confirmations from the affected human contributors have been obtained
and retained in project records. A maintainer's report that consent exists is
useful audit evidence but is not a substitute for preserving each
contributor's own confirmation.

## Method

The review used:

```sh
git shortlog --summary --email --all
git log --format='%aN <%aE>' --all
git log --format='%aN <%aE>|%cN <%cE>' --all
git log --numstat
git blame --line-porcelain
git blame -C -C --line-porcelain
```

It also searched current and historical files for SPDX tags, copyright and
licence notices, source URLs, copied/adapted markers, generated files,
submodules, vendored directories, binary assets, and DCO or co-author
trailers.

Commit `3b2b11212c6e322d45237dab82b8106380c7ee84`, titled “Apply supplied Watt
Cubed patch,” changed 50 files with 8,759 insertions and 3,292 deletions.

maintainer confirmed that they personally supplied the previously questioned

the licensing-transition records.

licence does not replace those terms or notices.

## AI assistance and DCO state

The history contains 58 Claude co-author trailers across 57 commits: Claude
Fable 5 and Claude Opus 4.8. These are development-tool provenance, not human
copyright-holder identities. The human submitter remains responsible for the
submitted material.

No historical commit contains a `Signed-off-by:` trailer. DCO enforcement is
therefore prospective; it cannot substitute for direct retroactive consent.

## Confirmation gate

Before pushing the licensing transition, retain a direct written confirmation
from each nontrivial human contributor. A suitable confirmation is:

> I confirm that I have the right to license my contributions to Project Watt
> Cubed and voxel-engine under GNU AGPL version 3 or any later version. For
> artistic and documentation contributions, I agree to Creative Commons
> Attribution-ShareAlike 4.0.

The project should record the confirmation date, contributor identity, scope,
and durable location of the original message without publishing unnecessary
private information.

After that gate is complete, future contributions use DCO 1.1 sign-offs under
the inbound-equals-outbound terms in [CONTRIBUTING.md](CONTRIBUTING.md).

The supplied licensing plan identifies the project lead as under 18. Before
publishing the transition, have a parent or guardian participate in the
project lead's initial licensing declaration and seek Swedish
intellectual-property advice where practical. This technical audit is not a
substitute for that review.
