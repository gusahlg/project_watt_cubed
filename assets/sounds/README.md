# Sound assets

`catalog.toml` is the runtime contract for short effects. Files are decoded once
at startup; repeated references share one decoded clip.

Each cue has a `response` (`world`, `ambient`, or `ui`) and one or more layers:

<!-- SPDX-SnippetBegin -->
<!-- SPDX-SnippetCopyrightText: 2026 Project Watt Cubed contributors -->
<!-- SPDX-License-Identifier: AGPL-3.0-or-later -->

```toml
[cues.example]
response = "world"
[[cues.example.layers]]
variants = ["custom/example-1.wav", "custom/example-2.wav"]
gain = [0.8, 1.0]
pitch = [-2.0, 2.0]
delay = [0.0]
mode = "one_shot"
```

<!-- SPDX-SnippetEnd -->

Paths must stay relative to this directory. Gain is `(0, 4]`, pitch is limited
to ±48 semitones, and delay to `0..=60` seconds. UI cues require zero delay.
All layers in one cue must use the same mode.

The files under `generated/` are deterministic placeholders. Run
`cargo run --features dev-tools --bin gen_tones -- --force` to regenerate them.
The generator skips existing files without `--force`, so it will not silently
overwrite replacements. Their `CC-BY-SA-4.0` sidecars and hashes in
`../attribution/generated-sounds.toml` are part of the asset provenance record;
update both whenever the generated bytes intentionally change.
