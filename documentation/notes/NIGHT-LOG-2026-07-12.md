# Night log — 2026-07-12

Directives: architectural redesigns (planned first, implemented carefully),
memory + fps optimization ideas, a MUCH higher block-combination limit,
blocks slightly smaller, and the element-worldgen plan implemented — extras
included. All work on the `experimental` branches (game + engine).

## Found on arrival

The repos were out of lockstep: engine main had been fast-forwarded to the
LOD rework, which the game had never compiled against (`Engine::set_flags`
never existed in engine history; two Settings test fixtures were stale).
Fixed both sides before any baseline was trusted.

## Landed

1. **Per-chunk palettes + the 16,384-block cap.** `ChunkData::Paletted`
   keeps cells one byte no matter how wide the global palette grows (GC on
   saturation; `Dense` full-width escape hatch past 256 distinct in one
   chunk — legal play, never a crash). BlockId is u16; the mesh vertex's
   layer field widened 8→14 bits INSIDE the same 8-byte vertex (word 0 had
   exactly six spare bits). Texture growth is incremental and clamps to
   `maxImageArrayLayers` — past it, vertex layers wrap with one loud log;
   crafting never fails. Save spec-table cap raised to match (was a silent
   4096 wall). Chunk RAM flat: rss within noise of baseline at 64× the ids.
2. **Element-first worldgen (the plan doc, landed in full).**
   `src/world/placement.rs`: closed vocabulary, builtin table, startup
   enumeration in canonical order (50 new naturals, registry at 75 ids —
   the doc's arithmetic), ENUM_CAP 1024, reactive-terrain audit at startup.
   Generator holds only resolved LUTs (cannot register, by construction).
   Censused against a frozen legacy picker: geometry byte-identical,
   materials map exactly (grass/dirt → natural unions, Obsidian gains its
   stone host — the accepted drifts). Stream B lands ore overlap pairs
   (arity ≤ 2 structurally); beach edges dither into Soil+Sand (+1 @ 1/2,
   +2 @ 1/4 — beach palms keep tree geometry exact); Lumin clusters on deep
   cavern floors/ceilings (vertical carve adjacency: one column, two reads,
   post-roll; deep-proof gains two dormancy sups and a dense-agreement
   test). Save v5 stamps worldgen_version (v4 loads + warns); protocol v4.
3. **Blocks read ~15% finer.** `math::BLOCK_METERS = 0.85`: the lattice
   never moves; every human length/velocity is authored in metres ×
   PER_METER (player 1.8 m ≈ 2.12 blocks, reach, speeds, gravity, jump,
   interest radius, chat range, avatar rig scaled at the body-local→world
   seam). Approach RATES (1/s) deliberately unscaled — timing identical.
4. **Frame loop reads as its phases.** update(): net → input (FrameInput
   snapshot) → overlay → motion → interact → stream; draw(): compose →
   scene → hud. Pure code motion — the golden check passed against the
   UNCHANGED blessed shots. Settings now flow through one path
   (`Game::apply_settings`) for world entry and `/gfx` alike.
5. **Memory:** edit-and-revert compacts out of the overlay (saves/joins
   stay proportional to real difference from seed); the server interns
   spec strings (`Arc<str>` pool — its only unbounded state); the engine
   allocator's FIRST block is 16 MiB (was 64 — most of idle GPU footprint),
   growth still 64.
6. **The golden harness is finally deterministic.** Three independent
   per-run wobbles found and fixed while gating the palette work: the live
   FPS readout baked into captures (pinned in scripted runs), captures
   firing before the far field fully refined (the varying horizon hole
   dragged the exposure meter — whole-frame LSB drift), and the blue-noise
   dither phase riding the capture's arbitrary frame index (pinned).
   Bless + two consecutive checks pass 19/19, repeatedly. Also: first-ever
   bless on a fresh checkout works now (creates tests/golden/), and
   benches pin their world seed (42; WATT_BENCH_SEED overrides).

## Decisions taken

  thread the stash through FIVE Mod-trait hooks, fattening the deliberately
  thin mod API for a contained, documented, sequential-access pattern.
  Reversed after contact with the code.
- Streaming state machine rework deferred (subtle, working, hot).
- Grass/dirt hue drift accepted per the plan doc; if the crust feels wrong
  in play, tune the ELEMENT colors, not placement semantics.
